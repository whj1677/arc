Arc 同事内测运行说明
2026-11-21

启动与升级

完整保留 Arc-win32-x64 目录，双击其中的 Arc.exe。若 Windows SmartScreen 提示应用未签名，点击「更多信息 → 仍要运行」。
升级前先关闭 Arc，再用新版覆盖整个 Arc-win32-x64 目录。个人历史数据保存在 %APPDATA%\Arc，覆盖程序目录后仍可继续使用。

前置环境

1. 本机需安装 Node.js，用于运行内置的冻结源码只读 MCP 工具。
2. 至少安装并登录以下一种工具：OpenAI Codex CLI（≥ 0.163.0，推荐使用 Codex Desktop 随附的 CLI 或 npm 版 CLI），或 DeepSeek Harness（DSH ≥ 0.2.1-rc.2）。
3. 如需使用「需求与开发」的差异对比与验证功能，建议安装 Git。

3 步快速上手

1. 打开 Arc，点击左下角「打开工程」，选择本地源码目录。Arc 全程只读访问原工程，并在本机生成冻结快照。要查看内置静态模块依赖，可直接切换到「代码模块依赖」，无需调用模型。
2. 顶部「分析方式」默认推荐 Codex 直连，也可切换到 DSH。在设置或菜单中可选择模型和推理强度，无需手动打开终端或另建桌面会话。
3. 在「工程全貌」点击「分析工程」，生成分层系统架构与功能目录。进入「功能走读」可查看首轮线索，也可点击「生成本组」或「批量选择」，按需展开函数调用链与调用时间图（双图）。

高级连接（可选）

如需接入已有 Codex 桌面会话或外部 Agent，可通过左下角「连接 Agent」启用本机 MCP / 桌面会话派发。

数据与安全边界

所有分析记录、快照与工程资料均保存在本机 %APPDATA%\Arc。调用模型分析时，所选快照的源码会发送到本机已登录的 Codex 或 DSH 所使用的模型服务。
静态分析与模型复核不等于运行时测试或硬件验证。

版本信息

目录内的 BUILD-INFO.json 记录对应的 Git 提交、构建时间与校验哈希。
