当前桌面会话执行方式（2026-11-16）

完整保留目录并双击 Arc.exe；无需打开 CLI 窗口。
在 Codex 桌面端打开同一个工程目录并创建会话，在 ARC 的“连接 Codex 桌面会话”中查找、选择并连接。
模型、推理强度、登录和权限在 Codex 桌面端管理；ARC 不覆盖原生权限。
ARC 只有收到 MCP 领取回执才显示执行中。队列受阻可检查连接重试；已发送而终态未知时先核对原会话，不重复发送。
本机已验证 Codex Desktop 随附 codex-cli 0.169.0-alpha.11.1 的 queue --resume 能力；后台会话服务使用本机已安装版本。
新电脑需要 Codex 已登录、支持 queue --resume 的官方 CLI、可用 app-server 后台服务及 Node.js。ARC 不包含这些依赖，也不复制原电脑的会话 ID。
依赖缺失时连接或派发会显示错误。干净 Windows 用户/其他电脑的真实联调尚未完成，不据此声称免配置部署。
BUILD-INFO.json 记录本包提交、构建时间及哈希。软件示例验证不代表 BMS 硬件验证。
